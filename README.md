# Laboratoire Merchan · website demo

A one-page website proposal for Laboratoire Merchan d'analyses médicales (Avenue Hassan II, Tanger), prepared as a demo to present to the lab. Not affiliated with the lab and not published.

Open `index.html` in a browser. Everything is in that one file: styles, scripts and the neighbourhood map (an inline SVG drawn from OpenStreetMap data, © OpenStreetMap contributors). Fonts, icons and photos load from Google Fonts, unpkg (Phosphor icons) and Unsplash, so it needs an internet connection.
